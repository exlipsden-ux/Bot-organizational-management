# 📦 Telegram-бот для управления организацией

Асинхронный Telegram-бот для автоматизации учёта сотрудников склада Ozon. Бот интегрируется с Google Sheets в качестве базы данных, проводит ежедневные опросы сотрудников, формирует отчёты для администраторов и ведёт статистику отработанных дней.

---

## 🚀 Возможности

### Для сотрудников
- 📝 **Регистрация** — ввод ФИО и номера телефона с сохранением в Google Sheets
- 🌅 **Утренний опрос** — подтверждение выхода на работу сегодня
- 🌇 **Дневной опрос** — подтверждение выхода на работу завтра
- 📍 **Получение рабочего места** — автоматическая рассылка сектора/позиции на день
- ❓ **Опрос по "?"** — уточнение готовности выйти, если в таблице стоит знак вопроса

### Для администраторов
- 📊 **Статистика** — общее количество сотрудников, на сегодня/завтра
- 📅 **Статистика за месяц** — количество отработанных дней по каждому сотруднику
- 👥 **Список работников** — с сортировкой по алфавиту или по секторам на любую дату
- ⏰ **Настройка времени** — динамическое изменение времени опросов и отчётов
- 👤 **Управление админами** — добавление новых администраторов
- 📈 **Ежемесячный отчёт** — количество зарегистрированных пользователей
- 🛠 **Мониторинг статуса** — проверка работоспособности и последних ошибок
- 📋 **Список участников** — кому придёт дневной опрос

### Автоматизация
- 🤖 **Планировщик APScheduler** — 5 автоматических задач по расписанию
- 🔁 **Фоновая проверка "?"** — каждые 2 минуты в диапазоне 10:00–23:00
- 📬 **Отправка логов** — критические ошибки автоматически отправляются администраторам
- 💾 **Кэширование листов** — через `lru_cache` и локальные JSON-файлы

## 📋 Структура Google Sheets

Таблица должна иметь следующую структуру:

| Столбец | Индекс | Назначение |
|---|---|---|
| A | 1 | ФИО сотрудника |
| B | 2 | Номер жилетки |
| C–AG | 3–33 | Даты месяца (формат `ДД.ММ.ГГГГ`) |
| AH | 34 | Номер телефона |
| AI | 35 | Telegram `chat_id` |

Каждый месяц — отдельный лист с названием вида `Январь 2026`, `Февраль 2026` и т.д.

В ячейках дат указывается:
- **Символ/сектор** (например, `A1`, `B2`) — сотрудник работает
- **`?`** — требуется уточнение
- **Пусто** — сотрудник не работает

## ⚙️ Установка и настройка

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/ozon-warehouse-bot.git
cd ozon-warehouse-bot
```

### 2. Установка зависимостей

```bash
pip install python-telegram-bot gspread oauth2client apscheduler httpx
```

### 5. Переменные окружения

Создайте файл `.env` или экспортируйте переменную:

```bash
export TELEGRAM_BOT_TOKEN_Ozon="YOUR_BOT_TOKEN_HERE"
```

### 6. Запуск

```bash
python main_ozon.py
```

## 🤖 Команды бота

### Пользовательские
| Команда | Описание |
|---|---|
| `/start` | Регистрация нового сотрудника |
| `/cancel` | Отмена текущего действия |
| `/help` | Список доступных команд |

### Административные
| Команда | Описание |
|---|---|
| `/stats` | Общая статистика сотрудников |
| `/stats_month` | Статистика отработанных дней за месяц |
| `/monthly_users` | Количество зарегистрированных за текущий месяц |
| `/workers` | Список работников с сортировкой |
| `/day_check_participants` | Участники дневного опроса |
| `/set_time` | Настройка времени опросов |
| `/add_admin <chat_id>` | Добавление администратора |
| `/status` | Состояние бота и последние ошибки |

## 📅 Расписание автоматических задач

| Время | Задача |
|---|---|
| **06:00** | Утренний опрос сотрудников |
| **07:00** | Отчёт админам об утреннем опросе |
| **07:05** | Рассылка рабочих мест сотрудникам |
| **09:30** | Дневной опрос (о завтрашнем выходе) |
| **12:05** | Отчёт админам о дневном опросе |
| **10:00–23:00** (каждые 2 мин) | Проверка сотрудников с символом `?` |

## 🔐 Безопасность

- Доступ к админ-командам ограничен списком `admin_chat_ids`
- Токен бота хранится в переменных окружения
- Критические ошибки логируются и отправляются администраторам
- Защита от рекурсивной отправки логов через флаг `in_sending`
- Обработка ошибок `Chat not found`, `Message is too long`, сетевых таймаутов
